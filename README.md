##  Hyprlock

In ``~/.config/hypr/`` u can change hyprlock.conf to modify the format. In same directory, u can change avatar.png and background.png 

## Rofi

- I'm using a custom theme of rofi, if you want more info to custom them, or just show all previews and themes, visit: 
	
	- https://github.com/adi1090x/rofi


In ``~/.config/rofi/powermenu/type-4`` u can change any parameters, or set another style to launch a beautiful menu.

In ``~/.config/rofi/launchers/type-3`` u can change any parameters too for the launcher menu here.

## Function ScreenShot

If you want to change the text of the notify-send when you take a screenshot, and you want to change your output directory, you need to go:

	``~/.config/hypr/scripts/function_screenshot/``
